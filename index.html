Um pouco sobre mim

Trabalho com desenvolvimento Java no dia a dia e comecei a programar estudando Python, JavaScript e SQL. Desde então, o que mais me interessa é criar coisas que resolvem um problema real, mesmo que pequeno.

Meus projetos pessoais vão de um controle financeiro e um calendário de diárias a relatórios com gráficos que funcionam direto no navegador, sem servidor. Também já automatizei testes com Robot Framework e brinquei com bots em Python.

Também crio sites para profissionais autônomos, com HTML, CSS e JavaScript puros, publicados no GitHub Pages.
